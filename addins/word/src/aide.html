Aide du correcteur

Ouvrez le panneau avec le bouton Corriger de l'onglet Accueil, puis cliquez sur Analyser le document.

  • Cliquez sur une carte pour afficher le passage dans le document.
  • Cliquez sur une suggestion pour l'appliquer.
  • « Ignorer » masque le problème jusqu'à la prochaine ouverture du panneau.
  • Le dictionnaire personnel et les réglages sont conservés sur cet ordinateur.

Toute l'analyse se fait sur votre ordinateur : le texte du document n'est jamais envoyé.
