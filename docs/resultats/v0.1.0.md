# Résultats — version 0.1.0

> **À lire avant les chiffres.** Le corpus d'évaluation est petit (26 phrases) et rédigé par le contributeur initial. Ces mesures servent de point de départ et de non-régression, pas de garantie de qualité. Des erreurs de grammaire figurent dans le corpus, mais aucune règle de grammaire n'existe encore (rappel nul attendu). Il faut un corpus plus large, idéalement des textes réels annotés, avant de tirer des conclusions.

Commande : `cargo run --release -p correcteur-cli -- evaluer`
