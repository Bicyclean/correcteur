# Modèles de conjugaison, rédigés pour ce projet d'après la conjugaison usuelle
# du français (source : REF-GRAM-FR).
#
# « modele NOM TERMINAISON » ouvre un modèle. Le radical d'un verbe est son
# infinitif sans la terminaison (« chanter » → « chant »). Chaque case est un
# suffixe ajouté au radical. « a/b » : deux formes admises (la première sert aux
# déductions). « - » : forme inexistante.
#
# Lignes obligatoires :
#   pres  les six personnes du présent de l'indicatif (je, tu, il, nous, vous, ils)
#   ps    les six personnes du passé simple
#   fut   le radical du futur, auquel s'ajoutent -ai, -as, -a, -ons, -ez, -ont
#   ppas  le participe passé ; « X inv » s'il est invariable ; ou quatre formes
#         masc. sing., masc. plur., fém. sing., fém. plur.
#
# Temps déduits (voir crates/correcteur-core/src/conjugation.rs), qu'une ligne
# du même nom remplace si le verbe fait exception :
#   impf  imparfait : radical de « nous » au présent + -ais, -ais, -ait, -ions, -iez, -aient
#   cond  conditionnel : radical du futur + terminaisons de l'imparfait
#   subj  subjonctif présent : radical de « ils » au présent + -e, -es, -e, -ent ;
#         « nous », « vous » comme à l'imparfait
#   subi  subjonctif imparfait : passé simple (2e pers. sans -s) + -sse, -sses, ^t, -ssions, -ssiez, -ssent
#   imp   impératif : 2e pers. sing., 1re et 2e plur. du présent (-es devient -e)
#   ppre  participe présent : radical de « nous » au présent + -ant
# « defectif 3s » : verbe impersonnel, seule la 3e personne du singulier existe.
